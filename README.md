# Latex Workshop

## Overview
A hands-on LaTeX Workshop: slides plus progressive hands-on exercises.
   
## Requirements
* A Web browser + An [Overleaf](https://www.overleaf.com/register) account

## Sofware
If you want to work offlline or don't want to open and overleaf account
* A Latex Distribution: [MiKTeX](https://miktex.org/download) or [TexLive](https://www.tug.org/texlive/acquire-netinstall.html)
* Latex Editor: [TEXMaker](https://www.xm1math.net/texmaker/download.html) (Optional, but recommended if you are trying latex for the first time.)
